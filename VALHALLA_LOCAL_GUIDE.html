SmartFleet Docker Environnement Local

Installation locale simplifiée de Valhalla

Ce guide explique comment faire tourner rapidement le moteur d'itinéraire Valhalla en local sur Windows (avec Docker Desktop / WSL2), configurer une carte de test, et y connecter votre backend Spring Boot.

Difficulté

Très Facile (via Docker)

Port Local

8002 (exposé par défaut)

Données Utilisées

Extraits OpenStreetMap (.osm.pbf)

1. Prérequis

  • Docker Desktop pour Windows installé et configuré avec le moteur WSL2.
  • Environ 2 Go à 4 Go d'espace disque disponible pour stocker les images Docker et les graphes de routage locaux.
  • Un terminal standard (PowerShell, Command Prompt ou Git Bash).

2. Pourquoi Docker en Local ?

Valhalla est écrit en C++ et dépend de dizaines de bibliothèques systèmes Linux spécifiques (Boost, GEOS, Prime Server, Spatialite...). Vouloir le compiler nativement sous Windows est un véritable casse-tête de développement.

L'avantage de Docker : L'image fournie par gis-ops intègre à la fois le serveur Valhalla précompilé et des scripts d'automatisation. Lors du premier lancement, elle s'occupe de télécharger la carte choisie, de générer le graphe de routage (les "tiles"), et de démarrer l'API sans aucune configuration manuelle !

3. Configurer le fichier docker-compose.yml

Votre projet backend intègre déjà un fichier de configuration Docker Compose prêt à l'emploi : docker-compose.yml.

Pour choisir votre zone géographique, il suffit d'ajouter la variable d'environnement tile_urls. Voici les configurations types recommandées :

Option A : Le Maroc (Idéal pour le projet SmartFleet final)

environment:
  - serve_tiles=True
  - build_admins=False
  - build_time_zones=False
  - tile_urls=https://download.geofabrik.de/africa/morocco-latest.osm.pbf

Option B : Monaco ou Andorre (Recommandé pour tester en moins de 2 minutes)

Le fichier du Maroc fait environ 20 Mo, ce qui est très léger. Cependant, si vous disposez d'une connexion lente, utiliser un tout petit pays comme Monaco (quelques kilo-octets) permet un démarrage instantané. 

environment:
  - serve_tiles=True
  - build_admins=False
  - build_time_zones=False
  - tile_urls=https://download.geofabrik.de/europe/monaco-latest.osm.pbf

4. Lancer le service

Pour lancer Valhalla en arrière-plan, exécutez cette commande dans votre terminal (à la racine de votre dossier backend) :

docker compose up -d valhalla
Que se passe-t-il au premier démarrage ?
1. Docker télécharge l'image de Valhalla.
2. Le script télécharge le fichier de carte .osm.pbf spécifié.
3. Il exécute les utilitaires de construction (valhalla_build_tiles) pour transformer les routes géographiques en modèle de graphe utilisable.
4. Il démarre l'API Valhalla sur le port 8002.
Ce processus initial prend de 1 à 5 minutes selon la taille du pays.

Pour suivre l'avancement de la construction et du téléchargement, utilisez cette commande :

docker compose logs -f valhalla

5. Valider l'installation

Une fois que les logs indiquent que le serveur écoute, ouvrez un terminal et lancez un test de santé :

curl http://localhost:8002/health

Si la réponse est positive, vous devriez obtenir :

{"status":"OK","version":"3.4.0"}

Vous pouvez également tester un calcul d'itinéraire réel. Par exemple, pour deux points à Monaco (si vous avez importé Monaco) :

curl "http://localhost:8002/route?json=\{\"locations\":\[\{\"lat\":43.7384,\"lon\":7.4246\},\{\"lat\":43.7410,\"lon\":7.4290\}\],\"costing\":\"auto\"\}"

6. Connexion avec Spring Boot

Pour lier votre application Spring Boot SmartFleet à votre moteur Valhalla local, ouvrez le fichier .env à la racine du projet backend et ajoutez ou modifiez la variable d'environnement : 

VALHALLA_URL=http://localhost:8002

Votre service java DeliveryOptimizationService.java effectuera ses calculs de distance, de temps et d'itinéraire directement sur votre conteneur local !

7. Astuces & Dépannage

Comment changer de pays / Réinitialiser la carte ?

Si vous modifiez l'URL de la carte dans docker-compose.yml pour passer de Monaco au Maroc, Valhalla ne mettra pas à jour les tuiles automatiquement car le volume est persistant. Pour forcer la régénération, videz le volume persistant et recréez le conteneur : 

# 1. Arrêter le conteneur
docker compose down

# 2. Supprimer le volume de données local
docker volume rm backend_valhalla_data

# 3. Relancer pour forcer le nouvel import
docker compose up -d valhalla

Port 8002 déjà utilisé ?

Si le port 8002 est utilisé par une autre application, modifiez le mappage de ports dans votre docker-compose.yml (ex: "8009:8002") et changez l'URL dans le fichier .env (ex: VALHALLA_URL=http://localhost:8009).

Bravo ! Votre environnement local est désormais prêt. Valhalla est configuré, rapide et ne nécessite aucun abonnement cloud pour calculer vos itinéraires de flotte.
