📋 PROJECT SUMMARY
═══════════════════════════════════════════════════════════════════════════════════

  SmartFleet est un système backend complet de gestion logistique avec:
  
  ✅ Optimisation des tournées de livraison (OR-Tools)
  ✅ Calcul d'itinéraires (Valhalla)
  ✅ Suivi en temps réel des conducteurs (WebSocket STOMP)
  ✅ Notifications push (Firebase)
  ✅ Authentification sécurisée (Clerk JWT)
  ✅ Données géospatiales (PostgreSQL + PostGIS)

📊 ENTITIES (JPA MODEL)
═══════════════════════════════════════════════════════════════════════════════════

  User (Abstract)
  ├── Manager (Responsable turnées)
  ├── Driver  (Conducteur + GPS tracking PostGIS)
  └── Client  (Expéditeur + Firebase token)

  Vehicle (Capacité m2 + kg)
  Order (Avec PostGIS Point pour livraison)
  DeliveryProgram (Regroupe commandes)
  SubProgram (Tournée = 1 Driver + 1 Vehicle + N Orders)

🔌 INTEGRATIONS
═══════════════════════════════════════════════════════════════════════════════════

  OR-Tools (Vehicle Routing Problem)
  ├─ Prend: Commandes + Véhicules + Conducteurs
  ├─ Retourne: Routes optimisées par véhicule/conducteur
  └─ Contraintes: Poids, Volume, Temps

  Valhalla (Route Optimization)
  ├─ Prend: Points de livraison
  ├─ Retourne: Polylines + Distances + Durées
  └─ Optimise: Ordre visite points

  Clerk (Authentication)
  ├─ Génère: JWT tokens
  └─ Backend: Valide via OAuth2 Resource Server

  Firebase (Notifications)
  ├─ Envoie: Notifications push conducteurs
  └─ Events: Itinéraire créé, Arrivée imminente, Tournée terminée

  PostgreSQL + PostGIS (Geospatial Data)
  ├─ Stocke: Positions drivers + Points livraison (geography type)
  └─ Queries: Trouvé drivers à proximité, ordres à proximité

  WebSocket STOMP (Real-Time)
  ├─ Driver: Envoie position toutes 30s
  └─ Clients: Reçoivent broadcast max 2 minutes

🚀 QUICK START

  3. mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=dev"
