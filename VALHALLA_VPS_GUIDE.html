SmartFleet Valhalla VPS

Guide complet pour déployer Valhalla sur une VPS

Ce document explique comment installer Valhalla sur une VPS Ubuntu, charger la carte du Maroc, générer les tiles, exposer le service et connecter le backend Spring Boot de SmartFleet.

Objectif

Faire tourner un service Valhalla stable et accessible depuis le backend.

Zone conseillée

Maroc via un extrait OpenStreetMap dédié.

Port par défaut

8002

1. Prérequis

  • Une VPS Ubuntu 22.04 ou 24.04.
  • 4 Go de RAM minimum, 8 Go recommandés.
  • Au moins 20 Go de disque.
  • Docker et Docker Compose installés.
  • Un extrait OpenStreetMap du Maroc au format .osm.pbf.
Si tu veux couvrir toute la production, évite d’utiliser un PBF mondial. Pour SmartFleet, le fichier Maroc est le bon choix.

2. Architecture recommandée

  • Valhalla tourne sur la VPS.
  • Le backend Spring Boot appelle l’URL publique de cette VPS.
  • Le service expose seulement le port 8002 ou un port HTTPS derrière un reverse proxy.
  • PostgreSQL/PostGIS peut être sur la même VPS ou sur une autre machine.

3. Préparer la VPS

Sur Ubuntu, installe Docker avec les commandes suivantes :

sudo apt update
sudo apt install -y ca-certificates curl gnupg lsb-release
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo \
  "deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable docker
sudo systemctl start docker

Vérifie ensuite :

docker --version
docker compose version

4. Télécharger la carte du Maroc

Le plus simple est d’utiliser l’extrait Geofabrik du Maroc :

sudo mkdir -p /opt/valhalla/data
cd /opt/valhalla/data
sudo apt install -y wget
wget https://download.geofabrik.de/africa/morocco-latest.osm.pbf
C’est la bonne base pour générer les routes marocaines sans traiter toute la planète OpenStreetMap.

5. Générer les tiles Valhalla

Valhalla ne route pas directement sur le fichier .osm.pbf. Il faut générer les tiles avant de lancer le service.

  1. Créer un dossier de travail, par exemple /opt/valhalla.
  2. Monter le fichier Maroc dans le conteneur Valhalla.
  3. Lancer l’étape d’import et de génération des tiles.
  4. Démarrer le service ensuite avec ces données persistantes.
sudo mkdir -p /opt/valhalla/config
cd /opt/valhalla

Les commandes exactes dépendent de l’image Valhalla utilisée. L’idée reste la même : un conteneur pour construire les tiles, puis un conteneur pour servir les requêtes.

6. Docker Compose pour la VPS

Ton fichier actuel est bien pour démarrer, mais pour une VPS il faut éviter le téléchargement de la planète entière. Il vaut mieux monter le PBF du Maroc localement.

Élément Conseil VPS
Source des données Fichier Maroc local morocco-latest.osm.pbf
Stockage Volume persistant pour les tiles Valhalla
Réseau Port 8002 exposé vers le backend
Sécurité HTTPS conseillé derrière Nginx ou Caddy
Dans ton docker-compose.yml, la variable tile_urls qui pointe vers la planète OpenStreetMap n’est pas adaptée à une VPS Maroc. Il faut la remplacer par une source locale ou par un flux d’import dédié.

7. Configurer SmartFleet

Dans le backend Spring Boot, l’URL Valhalla doit pointer vers la VPS :

valhalla.service.url=http://IP_DE_TA_VPS:8002

Si tu mets un reverse proxy HTTPS :

valhalla.service.url=https://valhalla.ton-domaine.tld

Le code déjà présent côté backend doit ensuite utiliser ValhallaRestClient et RouteCalculationServiceImpl pour calculer les routes, les polylines, la distance et la durée.

8. Tester l’installation

Une fois Valhalla lancé, teste la disponibilité du service :

curl http://IP_DE_TA_VPS:8002/health

Vérifie aussi que le backend peut joindre la VPS. Si le port est fermé, ouvre-le dans le firewall :

sudo ufw allow OpenSSH
sudo ufw allow 8002/tcp
sudo ufw enable
sudo ufw status

9. Sécurité et bonnes pratiques

  • Expose uniquement les ports nécessaires.
  • Préfère HTTPS en production.
  • Garde les tiles et la configuration dans un volume persistant.
  • Surveille les logs et la consommation mémoire.
  • Utilise un extrait pays plutôt que la planète entière pour limiter les ressources.
Pour SmartFleet, la meilleure stratégie est : VPS Ubuntu + Docker + extrait Maroc + Valhalla public + backend Spring Boot configuré avec l’URL de la VPS.

10. Résumé rapide

  1. Installer Docker sur la VPS.
  2. Télécharger l’extrait OSM du Maroc.
  3. Générer les tiles Valhalla.
  4. Lancer le service Valhalla sur le port 8002.
  5. Configurer valhalla.service.url dans SmartFleet.
